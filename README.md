# Etch-a-Sketch

A browser-based Etch-a-Sketch project built from The Odin Project specification.

## Features

- Default 16 × 16 drawing grid generated with JavaScript
- Draw by hovering over cells
- Resize grid (up to 100 × 100)
- Clear board
- Toggle between classic black ink and rainbow mode

## How to use

1. Open `index.html` in your browser.
2. Hover over the grid to draw.
3. Use **Resize Grid** to choose a new grid size.
4. Use **Clear** to erase the board.
5. Use **Rainbow: Off/On** to switch color modes.
